## 결과 해석

- 최종 공통 Development 배포본 `3add9910d64147f0aa7d24b77ed67056`에서 Steam 자동화 실행 **48회 통과, 0회 실패**를 기록했습니다.
- 에디터 전투 회귀검사 **19/19 통과**는 Steam 실행과 **별도 집계**이며 경고가 포함되어 있습니다.
- PC·노트북과 서로 다른 Steam 계정을 사용한 자동화 테스트로, 공개 Steam 방 8인 부하를 입증하는 자료는 아닙니다.
- **Codex 협업 및 자동화 러너**를 활용하여 테스트를 실행하고 검증 결과를 수집·정리했습니다.

## 공개 범위

- `Results.json`은 비공개 원본에서 가져온 **실행 결과 집계 파일**입니다. 파일 안의 상대 경로는 비공개 작업 공간에서 사용된 이력이며 연결된 실제 실행 로그는 공개하지 않았습니다.
- Markdown 4개 문서는 비공개 원본을 기반으로 **호스트명·로컬 경로·비공개 내부 링크를 정리한 공개용 편집본**입니다.
- 원시 PC/Laptop 실행 로그, 에디터 원본 시험 출력, 프로젝트 소스 및 게임 에셋은 비공개입니다.
- 일부 문서의 시험은 서로 다른 배포 시점에 수행됐으므로 해당 문서에 표시된 일자·리비전·조건을 기준으로 해석해야 합니다.

이 저장소의 내용은 게임 다운로드나 배포본이 아닌 **포트폴리오 검증 자료**입니다.
