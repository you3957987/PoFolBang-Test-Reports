# PoFolBang | 멀티플레이 검증 자료

**PoFolBang**은 Unreal Engine 5·C++ 기반 3인칭 멀티플레이 슈팅 게임입니다. 이 저장소는 포트폴리오에서 **게임 개발 및 검증 결과를 확인할 수 있도록 공개한 자료실**이며, 게임 소스 코드와 에셋은 포함하지 않습니다.

## 검증 결과 요약

| 구분 | 결과 | 기준 |
| --- | --- | --- |
| Steam 멀티플레이 자동화 | **48회 중 48회 통과** | 2026-11-19 최종 Development 배포본 |
| 에디터 전투 회귀검사 | **19회 중 19회 통과** | 2026-11-19, 경고 포함 |
| 초기 세션·맵 연결 | **6가지 조합 통과** | 2026-11-17 PC·노트북 호스트 교대 |

Steam 실행, 에디터 검사, 초기 연결 검사는 **서로 다른 테스트**이므로 합산하지 않았습니다.

## 자료 작성과 공개 범위

- **Codex 및 자동화 러너**를 활용해 테스트를 실행하고 결과를 수집·정리했습니다. 일부 검사는 에디터나 통제된 테스트 조건에서 실행됐습니다.
- `Results.json`의 영어 필드명은 기계 판독을 위해 **원본 그대로 유지**했습니다. 사람이 읽는 Markdown 보고서는 한국어로 정리했습니다.
- Markdown 문서는 비공개 원본을 참고해 **공개용으로 요약·편집한 자료**입니다. 장비 식별자와 로컬 경로, 외부에서 열리지 않는 내부 참조는 제외했습니다.
- PC·노트북의 원시 실행 로그, 개인 계정 정보, 소스 코드, 게임 에셋과 패키지 파일은 공개하지 않았습니다.
- **48/48 통과**는 해당 시점의 지정된 자동화 조건에서의 결과이며, 모든 네트워크 환경 또는 8명이 각각 참여한 공개 Steam 방의 검증을 뜻하지 않습니다.
